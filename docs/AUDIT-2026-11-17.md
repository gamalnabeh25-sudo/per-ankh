2. صفحة نارمر تعرض فقرة تعريفية قصيرة وحقولًا موجزة، وتذكر صراحة أن تفاصيل عملية التوحيد موضع نقاش. لا تحتوي العينة المقروءة على قائمة مراجع أكاديمية محددة.
3. صفحة الدولة القديمة تقدم ملخصًا عامًا عن الأسرات 3–6، الأهرامات، المجمعات الجنائزية، الإدارة، والمواقع. لا تتضمن العينة قائمة مراجع مفصلة.
4. صفحة بني حسن تقدم نبذة موجزة عن المقابر الصخرية والمناظر والعمارة، وتذكر أمثلة للمقابر. لا تتضمن العينة بيانات ببليوغرافية يمكن تتبعها.

6. الصفحة الرئيسية كبيرة جدًا مقارنة بصفحات التفاصيل؛ يلزم تحليل CSS/JS والصور والأداء قبل اقتراح تقسيمها أو إعادة بنائها.
7. لم يتم إجراء اختبار كامل لكل الروابط أو الوظائف أو إمكانية الوصول أو مؤشرات Core Web Vitals.
