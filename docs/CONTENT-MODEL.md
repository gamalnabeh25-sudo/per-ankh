# نموذج المحتوى الموحد — بر عنخ

الغرض هو توحيد بنية المعلومات وربطها، مع إبقاء الصفحات الحالية قابلة للعمل تدريجيًا.

## أنواع السجلات
- `king`: ملك/حاكم.
- `period`: عصر أو فترة انتقالية.
- `site`: موقع أثري.
- `monument`: مبنى أو أثر منفرد.
- `topic`: موضوع حضاري (دين، كتابة، اقتصاد، جيش، طب...).
- `artifact`: قطعة أثرية.
- `source`: مرجع أو مصدر أولي.

## الحقول المشتركة
- `id`: معرف ثابت لا يتغير بتغير عنوان الصفحة.
- `title_ar`, `title_en`: العنوانان العربي والإنجليزي.
- `slug`: مسار URL ثابت.
- `summary`: ملخص تحريري.
- `body_sections`: أقسام المحتوى المرتبة.
- `date_range`: تاريخ أو نطاق زمني مع صيغة عدم اليقين.
- `confidence`: documented / probable / disputed / unverified.
- `sources`: معرفات المراجع التي تسند الادعاءات.
- `related_entities`: روابط داخلية إلى سجلات ذات صلة.
- `last_reviewed`: تاريخ آخر مراجعة علمية.
- `editorial_status`: draft / needs_sources / reviewed / published.

## بنية الادعاء العلمي
ينبغي أن يكون الادعاء الدقيق قابلًا للإسناد منفردًا:
- `claim`: نص الادعاء.
- `source_id`: المرجع.
- `locator`: رقم الصفحة/الفصل/رقم القطعة/الرابط الداخلي بعد التحقق.
- `evidence_type`: primary / excavation_report / scholarly_book / peer_reviewed / institutional.
- `confidence`: درجة الثقة.
- `notes`: حدود الدليل أو الرأي المخالف.

## حقول متخصصة
### الملك
الأسماء والألقاب، الأسرة، الفترة، التسلسل الزمني، النسب (مع درجة الثقة)، الشركاء والأبناء (مع الإسناد)، الأحداث، المنشآت، الشواهد، المقبرة/المدفن، الألقاب الملكية.

### العصر
حدود الفترة، الأسر الحاكمة، سمات السلطة والإدارة، التطورات الاقتصادية والاجتماعية، العمارة والفنون، الشواهد الأثرية، نقاط الخلاف الزمني.

### الموقع
الإحداثيات، الإقليم التاريخي، تاريخ الاستيطان، الطبقات/المراحل، التخطيط، المنشآت، مواد البناء، النقوش والمناظر، نتائج الحفائر، حالة الحفظ، الوصول والحماية.

### الأثر/القطعة
المادة، الأبعاد، التقنية، مكان العثور، السياق الأثري، مكان الحفظ الحالي، رقم التسجيل، النقوش، التأريخ، حقوق الصورة.

## قواعد الربط
- كل ملك يرتبط بعصر/أسرة، وبالآثار والمواقع التي تشهد له.
- كل موقع يرتبط بالآثار المكتشفة فيه والبعثات والمنشورات.
- كل ادعاء يربط بمصدر محدد، وليس فقط بقائمة مراجع عامة في نهاية الصفحة.
- لا تنشأ صفحة مستقلة لكيان لمجرد ملء العدد؛ يجب أن تتوافر مادة موثوقة كافية.

## ملاحظة تقنية
هذا نموذج تحريري/بياني مقترح، وليس migration منفذًا على قاعدة Supabase. لا تغيّر قاعدة البيانات قبل فحص المخطط الحالي وسياسات RLS والنسخ الاحتياطية.
